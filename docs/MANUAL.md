# Gazo ユーザーマニュアル

## 1. Gazo とは

Gazo は、画像と動画を **暗号化されたアルバム（Vault）** に保存し、ギャラリー表示・タグ付け・キャンバス編集・重複整理ができるデスクトップアプリです。Cryptomator 互換形式のため、他の Cryptomator 対応ツールとも Vault を共有可能です。

---

## 2. インストールと起動

### 2.1 必要環境

- **JDK 17** 以上
- **Gradle**（ソースからビルドする場合）

### 2.2 ビルド

プロジェクトルートで以下を実行します。

```bash
gradle build          # ビルド + テスト
gradle fatJar         # 実行可能 JAR 作成
gradle jpackageWin    # Windows 用アプリイメージ（Windows のみ）
```

### 2.3 起動方法

**Gradle から:**

```bash
gradle run
```

**JAR から:**

```bash
java -jar build/libs/gazo-1.0-SNAPSHOT-all.jar
```

**Windows アプリイメージ:**

`build/jpackage/Gazo/Gazo.exe` を実行

---

## 3. 初回起動と Vault（アルバム）の設定

### 3.1 パスフレーズ入力

起動すると Vault の **パスフレーズ**（暗号化パスワード）入力画面が表示されます。

- 新規 Vault: 任意のパスフレーズを設定（忘れると復元不可）
- 既存 Vault: 作成時のパスフレーズを入力

画面下部の **「接続先切替…」** から、ローカルフォルダか WebDAV かを選べます。

### 3.2 接続先の種類

| 種類 | 説明 |
|------|------|
| **ローカルフォルダ** | PC 上のディレクトリに Vault を保存 |
| **WebDAV** | Nextcloud 等の WebDAV サーバー上に Vault を保存 |

前回の接続先は自動的に復元されます（設定: `~/.gazo/settings.properties`）。

### 3.3 WebDAV 接続

WebDAV を選ぶと以下を入力します。

| 項目 | 例 |
|------|-----|
| WebDAV URL | `https://example.com/remote.php/dav/files/username` |
| Vault パス | `/gazo-vault` |
| ユーザー名 | WebDAV ユーザー名 |
| パスワード | WebDAV パスワード |

WebDAV パスワードは設定ファイルに暗号化保存できます。Vault パスフレーズ自体は保存されません。

## 4. メイン画面の構成

### 4.1 タブ

| タブ | 内容 |
|------|------|
| **キャンバス** | 保存済みキャンバスのランダムプレビュー。スライドショー・編集への入口 |
| **画像** | サムネイル付きギャラリー。タグ・検索で絞り込み |
| **動画** | Vault 内の動画一覧 |

### 4.2 メニューバー

#### ファイル

| メニュー | 機能 |
|----------|------|
| 画像を追加… | ファイル選択ダイアログで画像をインポート |
| 動画を追加… | 動画をインポート |
| サムネイル再作成… | 全サムネイルを再生成 |
| 最近削除した画像を復元… | 論理削除された画像を復元 |
| アルバム変更… | Vault 接続先の切替・移行 |
| アルバムを物理バックアップ… | Vault を別フォルダへコピー |
| 物理バックアップ先を登録… | 定期同期用のバックアップ先を登録 |
| バックアップと同期… | 登録済み先と同期 |
| 物理バックアップ先の登録を解除… | 登録を削除 |
| 競合比較しきい値設定… | WebDAV 競合時の d値しきい値 |
| 終了 | アプリ終了 |

#### 操作

| メニュー | 機能 |
|----------|------|
| 重複/類似チェック… | Vault 内の重複・類似画像を検出・整理 |
| タグ一括追加… | チェックした画像にタグを追加 |
| タグ一括削除… | チェックした画像からタグを削除 |
| チェックした画像を削除… | 選択画像を Vault から削除 |

### 4.3 ステータスバー

- **アルバム( Local / WebDAV ):** 現在の Vault 接続先
- **同期状態** — WebDAV 同期の進捗
- **接続先切替…** — Vault 接続先を変更
- **インポート中:** — ファイル取り込み中のファイル名

## 5. 画像の追加

### 5.1 メニューから

**ファイル → 画像を追加…** でファイルを選択します。複数選択可能です。

### 5.2 ドラッグ＆ドロップ

メインウィンドウに画像ファイルやフォルダをドロップすると取り込まれます。

### 5.3 対応形式

| 種別 | 拡張子 |
|------|--------|
| 画像 | `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp` |
| 動画 | `.mp4`, `.webm`, `.m4v`, `.mov`, `.mkv` |

取り込み時にサムネイルが自動生成されます。

---

## 6. 画像タブ（ギャラリー）

### 6.1 ツールバー

| 操作 | 説明 |
|------|------|
| 全選択 / 選択解除 | 表示中の画像を一括チェック/解除 |
| 選択を削除 | チェックした画像を削除 |
| キャンバス | キャンバス編集ダイアログを開く |
| ランダム | ランダムキャンバスを開く |
| タグフィルター | タグで絞り込み（複数選択可） |
| ファイル名検索 | ファイル名の部分一致検索 |
| 表示オプション | ファイル名・日付・タグの表示 ON/OFF |
| 一覧サイズ | 小 / 中 / 大 |

右端に **「表示 N / 全 M 枚」** と件数が表示されます。

### 6.2 カード操作

各画像カードをクリック/右クリックすると:

- **原寸表示** — オリジナル画像ビューア
- **タグ編集** — その画像のタグを編集
- **重複/類似チェック** — その画像を起点に類似検索

カード左上のチェックボックスで複数選択し、一括タグ操作や削除ができます。

---

## 7. タグ

### 7.1 タグの付け方

- カードの右クリック → **タグ編集**
- **操作 → タグ一括追加…** / **タグ一括削除…**（複数選択時）
- フォルダ取り込み時にフォルダ名がタグとして付与される場合あり

### 7.2 タグで絞り込み

画像タブのツールバーでタグを選択すると、該当タグを持つ画像のみ表示されます。「未タグ」フィルターも利用できます。

---

## 8. キャンバス機能

### 8.1 キャンタブ（ホーム）

- 保存済みキャンバスの **ランダムプレビュー** を表示
- **別のキャンバス** — 別レイアウトをランダム表示
- **スライドショーで開く** — フルスクリーン風スライドショー
- **キャンバス編集で開く** — 編集ダイアログを開く

### 8.2 キャンバス編集ダイアログ

画像タブの **キャンバス** ボタン、またはメニューから開きます。

主な機能:

- Vault 内の画像をキャンバスに追加・削除
- **ランダムピック** — 条件に合う画像をランダムに配置
- **自動レイアウト** — 「コラージュ風」「整列風」プリセット
- 画像の移動・拡大縮小・回転
- 複数キャンバス（レイアウト名）の作成・切替・保存
- **スライドショー** — キャンバス内容をスライドショー表示

## 9. 動画タブ

**ファイル → 動画を追加…** または DnD で動画を取り込み、動画タブで一覧・再生できます。画像タブと同様にタグフィルターが利用できます。

---

## 10. 重複/類似チェック

**操作 → 重複/類似チェック…** または、画像カードから個別に起動できます。

### 10.1 できること

- Vault 内の **完全重複**（同一ファイル）と **類似画像**（dHash ベース）を検出
- グループ単位で「残す画像」を選び、不要な画像を削除予約
- 削除はダイアログを閉じるかアプリ終了時に実行（即時削除ではない）

### 10.2 ギャラリーからの起動

- 1 枚のカード → その画像を起点に類似検索
- 複数チェック → 選択画像を起点に検索

---

## 11. 画像の削除と復元

### 11.1 削除

- **操作 → チェックした画像を削除…**
- 画像タブの **選択を削除** ボタン

削除された画像は `.gazo-trash` に移動され、すぐには物理削除されません。

### 11.2 復元

**ファイル → 最近削除した画像を復元…** から、削除日時付きの一覧から復元できます。

---

## 12. アルバム（Vault）の変更とバックアップ

### 12.1 接続先の切替

- ステータスバーの **接続先切替…**
- **ファイル → アルバム変更…**

別のローカルフォルダや WebDAV に切り替えられます。データの **移行**（コピー）オプションも選べます。

### 12.2 物理バックアップ

| 操作 | 用途 |
|------|------|
| アルバムを物理バックアップ… | その場で別フォルダへワンショットコピー |
| 物理バックアップ先を登録… | 接続先ごとにバックアップ先を記録 |
| バックアップと同期… | 登録先と最新状態を同期 |

暗号化された Vault ディレクトリ全体がコピーされるため、パスフレーズが同じであれば別 PC からも開けます。

## 13. WebDAV の同期と競合

### 13.1 同期の流れ

1. 起動時、ローカルキャッシュがあれば先に解錠して UI を表示
2. バックグラウンドでリモートとの差分同期
3. ステータスバーに進捗表示

大規模同期中は画面が一時的に操作不能になる場合があります。

### 13.2 競合が起きたとき

ローカルとリモートの両方で同じファイルが更新されると、**WebDAV 同期競合** ダイアログが表示されます。

| 選択肢 | 意味 |
|--------|------|
| ローカルを優先 | ローカル版で上書き |
| リモートを優先 | サーバー版を取り込み |
| 競合コピーを保存 | 別名 `(conflict yyyyMMdd-HHmmss)` で両方残す |
| キャンセル | 同期を中断 |

画像の場合、左右プレビューと **d値（dHash 距離）** が表示されます。しきい値はダイアログ内または **ファイル → 競合比較しきい値設定…** で調整できます。

## 14. コマンドライン（CLI）取り込み

GUI を開かずに画像だけ Vault へ登録できます。

```bash
java -jar build/libs/gazo-1.0-SNAPSHOT-all.jar import [オプション] <パス>...
```

### 14.1 主なオプション

| オプション | 説明 |
|-----------|------|
| `--vault <dir>` | Vault ディレクトリ（省略時は前回または `~/.gazo/vault`） |
| `-r` / `--recursive` | ディレクトリを再帰的に取り込み |
| `--webdav-endpoint <url>` | WebDAV URL |
| `--webdav-base-path <path>` | WebDAV 内 Vault パス |
| `--webdav-username <name>` | WebDAV ユーザー名 |

### 14.2 パスフレーズの渡し方（優先順）

1. 環境変数 **`GAZO_PASSPHRASE`**
2. `--password`（非推奨: シェル履歴に残る）
3. 対話入力

WebDAV パスワードも同様に **`GAZO_WEBDAV_PASSWORD`** が推奨です。

### 14.3 終了コード

| コード | 意味 |
|--------|------|
| 0 | 成功 |
| 1 | 引数エラー |
| 2 | Vault 不在 / 解錠失敗 |
| 3 | 一部ファイルの取り込み失敗 |

### 14.4 使用例

```bash
# 環境変数でパスフレーズを渡して再帰取り込み
export GAZO_PASSPHRASE='your-passphrase'
java -jar build/libs/gazo-1.0-SNAPSHOT-all.jar import -r /path/to/photos

# Gradle から
gradle run --args="import -r C:\Pictures\album"
```

## 16. トラブルシューティング

### Vault を開けない

- パスフレーズが正しいか確認
- Vault ディレクトリに `vault.cryptomator` と `masterkey.cryptomator` があるか確認
- 別の Cryptomator アプリで同じ Vault が開けるか試す

### WebDAV に接続できない

- URL・ユーザー名・パスワードを再確認
- ファイアウォール / VPN の影響を確認
- Nextcloud 等では WebDAV パス形式（`/remote.php/dav/files/ユーザー名`）が正しいか確認

### 同期が遅い / 毎回フル同期される

- 初回またはキャッシュ削除後は時間がかかります
- 2 回目以降は差分同期のため高速化されます

### WebDAV で dir.c9r の競合が頻発する

- 複数端末・複数アプリで同時に Vault を触ると Cryptomator のフォルダ ID が食い違うことがあります
- 競合ダイアログの説明を参照し、基本的に **片方の端末だけ** で Vault を更新する運用を推奨

### メモリ不足

- 大量画像のギャラリー表示ではヒープを増やしてください: `java -Xmx2g -jar ...`

### サムネイルが表示されない

- **ファイル → サムネイル再作成…** を実行

---

## 17. ショートカットと Tips

- 画像を DnD するだけで取り込み可能
- ギャラリーの表示サイズ・フィルター設定は次回起動時も保持
- CLI の `import` はバッチ処理や cron との連携に便利
- 物理バックアップを定期的に取ると、Vault 破損時の復旧が容易
